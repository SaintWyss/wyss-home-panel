# Seguridad

Yo recibo reportes privados mediante GitHub Security Advisories. Yo no publico tokens, claves Tuya, certificados privados, archivos `.env`, NVS ni respaldos de Flash.

Yo mantengo soporte de seguridad para la última versión estable. Yo priorizo fallas de autenticación, ejecución fuera de la allowlist, filtración de secretos, bypass de confirmación y downgrade de TLS.

Yo documento el modelo completo en [docs/security.md](docs/security.md).
